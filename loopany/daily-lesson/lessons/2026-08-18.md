## Track A · Rust

### Concept

`insert` **overwrites**, so before inserting you often want to ask: *is this key already here?*

```rust
if !basket.contains_key(&Fruit::Banana) {
    basket.insert(Fruit::Banana, 1);
}
```

`contains_key` gives you a plain `bool`. `basket.get(&key)` answers the same question with more
detail — `Some(n)` if the key is there, `None` if it isn't.

That `Option` is the shape you're about to meet in chess: a square either holds a piece or it
holds nothing.

## Track B · DSA

### Concept

A `u64` is 64 bits in a row. Number them from the **right**: bit 0 is the rightmost, bit 63 the
leftmost. Eight bits make one **byte**, so a `u64` is 8 bytes.

`<<` shifts every bit **left**, toward higher numbers. `>>` shifts right. Bits pushed off the
end are gone; zeros fill in behind.

```
     bit:   7 6 5 4 3 2 1 0
x  = 5      0 0 0 0 0 1 0 1
x << 1      0 0 0 0 1 0 1 0   = 10
x << 2      0 0 0 1 0 1 0 0   = 20
x >> 1      0 0 0 0 0 0 1 0   = 2    (the low 1 fell off the end)
```

Left by one doubles, right by one halves. That's the whole mechanism: `x << n` adds `n` to
every set bit's index, all in one instruction.

Now yesterday's connection. On a bitboard the index rule is the same one you wrote in
`Square::from_name`:

```
index = rank * 8 + file
```

Adding **8** to an index adds **1 to the rank** — one byte, one rank. So `pieces << 8` walks
every piece up a rank at once, and `pieces >> 8` walks them down. Shifting the number moves the
pieces.
