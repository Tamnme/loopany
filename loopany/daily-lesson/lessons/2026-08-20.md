### Concept

`entry` returns a handle to a slot — present or not. `or_insert(v)` fills it if empty;
`or_default()` fills it with `T::default()`. Either way you get back a **`&mut` to the value**,
so you can keep going:

```rust
let e = scores.entry(name).or_default();   // &mut TeamScores, zeroed if new
e.goals_scored += scored;                  // ...then add into it
```

That's the difference from `insert`, which *replaces*. England plays three times in the input;
`insert` keeps only the last row, `entry` + `+=` accumulates all three.

## Track B · DSA

### Concept

Same idea as yesterday, one node at a time.

Each position is a node. White wants the score **big**, Black wants it **small**. So at a
White node take the largest child; at a Black node take the smallest. Score the bottom row
first, then walk up.

```
        White (max)          -> max(+1, -2) = +1, so White plays left
        /         \
   Black (min)   Black (min)
    /    \        /    \
  +1     +4     -2     +9
```

The left Black node keeps `min(+1, +4) = +1`. The right one keeps `min(-2, +9) = -2`. White
compares `+1` and `-2` and goes left — even though `+9`, the best leaf on the board, is down
the right branch. It's unreachable because getting there means letting **Black** choose, and
Black picks `-2`.
