## Track A · Rust

### Concept

A `Vec` finds things by position: `v[3]`. A `HashMap` finds them by whatever you like — a
`String`, an enum, a `char`. You hand it a **key**, it hands back the **value**.

```rust
use std::collections::HashMap;

let mut basket = HashMap::new();
basket.insert(String::from("apple"), 3);   // key -> value
```

`insert` on a key that's already there **overwrites** the old value; there is only ever one
value per key. `len()` counts keys, not values — three apples and two bananas is `len() == 2`.

## Track B · DSA

### Concept

A **bitboard** is one `u64` where each bit is one square. Bit 0 is `a1`, bit 63 is `h8`, and
the rule is the same one you already wrote in `Square::from_name`:

```
index = rank * 8 + file
```

So `e4` — file `e` = 4, rank `4` = 3 — is bit `3 * 8 + 4` = **28**. One `u64` holds "where are
all my pawns" in 8 bytes, and `pawns << 8` slides *every* pawn up one rank in a single
instruction, because adding 8 to an index means adding one rank.

That's the whole idea: **shifting the number moves the pieces**.
